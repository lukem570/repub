# Keyboard shortcuts

Lists all keyboard shortcuts in Repub. Shortcuts follow Microsoft Publisher conventions where possible, adapted for cross-platform use.

## Conventions

| Windows/Linux | macOS | Role |
|---------------|-------|------|
| `Ctrl` | `Cmd` (⌘) | Primary modifier |
| `Alt` | `Option` (⌥) | Secondary modifier |
| `Shift` | `Shift` (⇧) | Extend/constrain |
| `Windows` | `Control` (⌃) | System modifier |

Notation:

- `+` means hold together (`Ctrl+S`).
- `,` means press in sequence (`F1, C`).
- `/` separates alternatives (`Ctrl+Y / Ctrl+Shift+Z`).

## Platform notes

macOS:

- `Ctrl` becomes `Cmd` (⌘) for most shortcuts, and `Alt` becomes `Option` (⌥).
- `Ctrl+Q` becomes `Cmd+Q` (Quit).
- `Cmd+Backspace` is used for Delete in some contexts.

Linux:

- Some systems use the `Super` key instead of the `Windows` key.
- The window manager may intercept `Alt+F4`.
- Function keys may require the `Fn` key on some keyboards.
